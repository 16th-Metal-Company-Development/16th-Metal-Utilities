Hello all,

Welcome to an adaptive music mod for ARMA 3 that I have revived and can no longer find on ARMAHolic or BI Forums.

This mod has been orignially created as a map script by Niklas Brettschneider and has been sitting on my hard drive for
years. I have made this mod completly independent of any map scripting and will work on any singleplayer or multiplayer
senario.

Special Thanks to Phenois for contributing some quality of life features and fixes.


You can tear apart this mod and create custom music packs and I will have a tutorial writeup file and video on the workshop page. (video at Somepoint)




Please keep in mind, if you do repost this. Make sure you follow Workshop guidlines and credit my workshop page and orignial
creator of the script.

The script is meant to be open to the public. You can check out the Github page here and can help contribute to the development
of this project:https://github.com/cheif22/ARMA3_adaptive_music
